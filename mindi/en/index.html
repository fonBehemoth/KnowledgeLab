Activity journal

FAQ

A few things to know

Is MINDI a website or a desktop application?

MINDI is a desktop application. This website introduces the product. The corporate server component is deployed separately in the company’s infrastructure.

Where is data processed?

The corporate version is designed for company infrastructure. The actual data route depends on the processing mode and connected services.

Who can see documents and employees?

Users with the relevant permissions. A job title does not automatically grant access. Reading a document and using it with an agent require separate permissions.

Can we connect our business systems?

The particular system, data and exchange process are considered during integration design. A universal ready-made connector is not currently claimed.

What does the 30–50% estimate mean?

It is GENRON’s preliminary expert estimate for aggregate operating expenses over approximately 7–11 months. It is neither a guarantee nor a measured implementation result.

How are pricing and timelines determined?

Commercial terms and timelines have not yet been defined for this concept. You can prepare a request for a demonstration, consultation or pilot discussion.
