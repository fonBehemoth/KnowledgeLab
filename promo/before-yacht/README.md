# Центрифуга / DeepAgent AI — монтаж до сцены на яхте

Черновая сборка: 85 секунд, 1920 × 1080, 24 кадра/с, без звука.

| Время | Сцена |
|---|---|
| 00:00–00:10 | Материалы → показатели → процесс для автоматизации |
| 00:10–00:22 | Аудит: рост выручки, снижение маржи, проверка причин |
| 00:22–00:34 | Учётные системы → правила и бизнес-логика → контроль |
| 00:34–00:46 | Аудит, пилот, оптимизация, стратегия развития |
| 00:46–00:55 | Целевой ориентир 70–80% для выбранных аналитических функций |
| 00:55–01:07 | Настройка ИИ-аналитика, ввод и назначение задачи |
| 01:07–01:16 | Отчёт с источниками, согласование и задача закупкам |
| 01:16–01:25 | Локальная инфраструктура, мобильное приложение, подводка к яхте |

Компания-разработчик: Центрифуга. Продукт: DeepAgent AI.
Интерфейс и показатели в ролике демонстрационные. 70–80% — целевой ориентир, а не подтверждённый результат. Реалистичную сцену на яхте пользователь готовит в Google Flow; она добавляется после этой части.

`index.html` — исходник сцен с детерминированным `window.renderFrame(seconds)`.
`render.cjs` — экспорт через Microsoft Edge и FFmpeg. Аргумент `--preview` сохраняет проверочные кадры.
Исходник index.html самодостаточен. Черновики v1/v2 сохранены как архив для продолжения монтажа.

Для рендера нужны Node.js, Playwright с Microsoft Edge и FFmpeg с libopenh264. Можно указать PLAYWRIGHT_MODULE и FFMPEG_PATH. Запуск: `node render.cjs --preview` для кадров или `node render.cjs` для экспорта. Новый экспорт записывается в отдельный файл и не перезаписывает v1/v2.
