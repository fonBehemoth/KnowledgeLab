# Проверки демо

Нужны Node.js, Playwright и Microsoft Edge. Можно указать PLAYWRIGHT_MODULE.

`node qa/check-telegram-chat.cjs` — единая лента, показатели уходят вверх, ввод, история и разные размеры окна.

`node qa/check-chat-history.cjs` — даты, входящие обращения, письма, сохранение, разделение компаний.

`node qa/check-position-picker.cjs` — должности, выбор сотрудников и ИИ-агентов, задачи.

Для проверки сайта передать URL вторым аргументом. Снимки записываются во временную папку. Это автоматические проверки в браузере, не проверки на физических устройствах.
