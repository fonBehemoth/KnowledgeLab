# DeepAgent AI — публичное демо

Продукт компании «Центрифуга».

Открыть: https://fonbehemoth.github.io/KnowledgeLab/

Интерфейс организован как мессенджер: навигация, компания, подразделение, материалы, история, режимы диалога и настройки находятся слева. Панель можно скрывать; последние переписки открываются прямо из неё. Верхней панели действий нет. Внизу основной области постоянно доступна строка сообщения с кнопкой добавления файлов.

Светлая тема: чисто белый фон, графитовый текст, голубые неоновые пиктограммы. Тёмная: графитовый фон, светлый текст, голубые пиктограммы. Шрифт DIN Pro. Рамки кнопок убраны; остаются разделители панелей. Тема переключается внизу слева и в настройках.

Все компании, люди, поручения и показатели вымышлены. Готовый аналитический пример открывается пунктом «Аналитика»; там доступны два типа графика, CSV и печать в PDF. Ответы ассистента заранее подготовлены. Файлы можно выбирать и удалять перед отправкой, но публичное демо не читает, не загружает и не анализирует их содержимое. В истории сохраняются только имена выбранных файлов. Доставка сообщений и учётные системы не подключены.

Демонстрационные изменения хранятся в localStorage этого браузера без синхронизации между устройствами. Сброс доступен в настройках. Не вводите конфиденциальные данные.

index.html открывает статическое приложение из preview/. promo/ и docs/ сохраняют ранее подготовленные презентационные материалы. Исходники сервера, ключи, настройки и рабочие данные закрытого приложения сюда не входят.

Открывать через GitHub Pages или статический HTTP-сервер. Установка зависимостей не требуется; file:// не поддерживается из-за модулей и JSON.

GitHub Pages: main, / (root).
