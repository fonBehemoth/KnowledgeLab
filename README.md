# DeepAgent AI — демо интерфейса

Продукт компании «Центрифуга». Интерактивный прототип для презентации инвесторам.

Фирмы, подразделения, персонал, ИИ-агенты, задачи, результаты и отчёты. Кнопка «Показать маршрут» запускает демонстрацию процесса. Фирмы переключаются стрелками, точками и колесом мыши над панелью выбора фирмы.

Данные условные. Ответы ИИ имитируются. Учётные системы в этой демонстрационной версии не подключены. Действия выполняются в памяти браузера и сбрасываются после перезагрузки.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

Открыть локально: index.html. Сборка и зависимости не требуются.
