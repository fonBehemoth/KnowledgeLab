# DeepAgent AI — публичное демо интерфейса

Продукт компании «Центрифуга».

Открыть: https://fonbehemoth.github.io/KnowledgeLab/

Обновление 18 октября 2026: новая компоновка и сравнение четырёх палитр. Сверху переключаются готовый отчёт, длинная переписка и карточка сотрудника. В приложении работают выбор компании и отдела, скрываемая навигация, меню материалов и анализа, история чатов и постоянная строка сообщения. Шрифт DIN Pro.

Все компании, люди, поручения и показатели вымышлены. В готовом аналитическом примере переключаются линейный и столбчатый графики; таблица выгружается в CSV, PDF сохраняется через диалог печати браузера. Новые документы не анализируются. Ответ ассистента заранее подготовлен и не зависит от введённого запроса. Доставка сообщений и учётные системы не подключены.

Изменения демонстрационных задач и переписок сохраняются только в localStorage текущего браузера, без синхронизации между устройствами. Сброс доступен в настройках демо. Не вводите конфиденциальные данные в публичный макет.

index.html, review.js, review.css — оболочка сравнения; preview/ — статическая версия текущей компоновки с синтетическими данными. promo/ и docs/ содержат ранее подготовленные презентационные материалы.

Запускать через статический HTTP-сервер либо GitHub Pages; открытие файлов напрямую через file:// не поддерживается из-за ES-модулей и загрузки JSON. Сборка и установка зависимостей не требуются.
