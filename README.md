# DeepAgent AI — публичное демо

Продукт компании «Центрифуга».

Постоянная ссылка для показа: https://fonbehemoth.github.io/KnowledgeLab/

При открытии страница проверяет release.json без браузерного кэша и загружает согласованный комплект файлов актуальной сборки. Адрес в строке браузера остаётся постоянным. Если новая сборка появилась во время работы, страница предлагает обновить её кнопкой, не прерывая переписку автоматически. Номер версии виден в настройках.

В публикации остаются текущая и предыдущая сборки. Генератор удаляет более старые каталоги releases; старые ссылки на выпуски через 404.html переводят на постоянный адрес. История коммитов Git сохраняется. Шрифты новой сборки используются из общего assets/.

Навигация находится слева, сохранённые переписки открываются через «Историю». Подразделение, сотрудник и выбранное действие закреплены сверху полупрозрачными капсулами. Внизу постоянно доступна строка сообщения; меню «+» содержит файлы и участников. Микрофон и видео — планируемые возможности без доступа к устройствам. Светлая тема белая, тёмная графитовая, пиктограммы голубые, шрифт DIN Pro. Тема выбирается в настройках.

Компании, люди и показатели вымышлены. Ответы заранее подготовлены; доставка сообщений, анализ новых файлов и учётные системы здесь не подключены. Изменения демо, переписки и настройки хранятся локально в браузере и не синхронизируются между людьми и устройствами. Сброс доступен в настройках. Исходники сервера, ключи и рабочие данные закрытого приложения не публикуются.

Генератор: output/interface-palette-lab/build_public_review.py в рабочем проекте; резервная копия — tools/workspace-lab в закрытом репозитории. GitHub Pages: main, / (root). Открывать через HTTP; file:// не поддерживается.
