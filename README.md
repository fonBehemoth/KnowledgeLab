# DeepAgent AI — демо интерфейса

Продукт компании «Центрифуга». Интерактивное демо для презентации инвесторам.

Открыть: https://fonbehemoth.github.io/KnowledgeLab/

Возможности:
- Компания → отдел → раздел → сотрудник (в разделе «Персонал»). ФИО и должность показаны отдельно; в отделе несколько менеджеров.
- Компании переключаются стрелками, точками, колесом мыши над панелью и горизонтальным свайпом.
- Задачи разделены по компаниям, отделам и сотрудникам.
- Последняя активность выбранного сотрудника отображается в шапке.
- В чат можно включить одного, нескольких или всех менеджеров выбранной компании. Состав участников можно менять.
- Ассистент и чат менеджеров — отдельные режимы. Чаты разных компаний разделены.
- Отчёты фильтруются по датам: день, последние 7 дней, последние 3 дня, текущий месяц, текущий год, произвольный период. Показатели пересчитываются.
- Раздел «Чаты»: переписки с группировкой по датам, входящие обращения, черновики и отложенные письма. Прочитанные обращения остаются в истории.
- Темы: «Белая ночь · оливка», «Тёплый лён · песок», «Мягкий шалфей».

Ограничения: данные, активность сотрудников и финансовые операции условные. Ответы ассистента демонстрационные. Учётные системы, приглашения и доставка сообщений не подключены. Задачи, история активности, чаты, черновики, отложенные письма и оформление сохраняются в localStorage этого браузера. Синхронизации между устройствами нет; очистка данных сайта удалит историю. Отложенные письма демонстрируют планирование, автоматическая отправка не подключена.

Запуск: открыть index.html или запустить статический HTTP-сервер. Сборка и зависимости не требуются.

GitHub Pages: main, / (root).
